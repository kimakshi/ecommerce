Important note for localhost
On XAMPP/WAMP, PHP "mail()" usually does NOT work by default.
To send real emails you should configure SMTP.

SMTP configuration (recommended)
Mailer reads environment variables:
SMTP_HOST
SMTP_PORT (example: 587)
SMTP_USER
SMTP_PASS
SMTP_SECURE (example: tls)
MAIL_FROM_EMAIL
MAIL_FROM_NAME

How to set env vars (live hosting)
- In cPanel/hosting: set these as environment variables.
- If you deploy on VPS: set in Apache/Nginx/PHP-FPM env config.

If you use Gmail SMTP
- SMTP_HOST=smtp.gmail.com
- SMTP_PORT=587
- SMTP_SECURE=tls
- SMTP_USER=yourgmail@gmail.com
- SMTP_PASS=Gmail App Password (NOT your normal password)
- MAIL_FROM_EMAIL=yourgmail@gmail.com
- MAIL_FROM_NAME=Chaatku
